Backend Implementation
Python (Pillow)
from PIL import Image

img = Image.open("generated.jpg")
wm = Image.open("watermark@2x.png")

# Calculate position
pos = (img.width - wm.width - 64, img.height - wm.height - 93)

# Paste with alpha mask
img.paste(wm, pos, wm)
img.save("output.jpg")
NumPy (Direct Tensor Manipulation)
# img: (H, W, 3) numpy array, wm: (h, w, 4) with alpha
h, w, _ = wm.shape
y = img.shape[0] - h - 93
x = img.shape[1] - w - 64

# Alpha blending
alpha = wm[:, :, 3:] / 255.0
img[y:y+h, x:x+w] = (1 - alpha) * img[y:y+h, x:x+w] + alpha * wm[:, :, :3]
FFmpeg (Video)
ffmpeg -i input.mp4 -i watermark@2x.png -filter_complex "overlay=W-w-24:H-h-35" output.mp4
ImageMagick (Image)
magick composite -gravity SouthEast -geometry ++64+93 watermark@2x.png input.jpg output.jpg
