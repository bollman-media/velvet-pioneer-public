# Design Coach

Read the skill file at `.agents/skills/design-coach/SKILL.md` and follow it exactly.

Perform a full component audit on whatever the user points at (screenshot, URL, component name, or code). If nothing is specified, audit the most recently discussed UI element.

Work through every section in order:
1. First Impression (2 seconds)
2. Hierarchy Analysis
3. Spatial Rhythm
4. Typography Audit
5. Color & Contrast
6. Motion & Interaction (if applicable)
7. The Lesson — distill the audit into ONE principle the user should internalize

Always teach, never just judge. The user's own work is the textbook.
