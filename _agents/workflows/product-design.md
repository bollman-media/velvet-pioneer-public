# Product Design Critique

Read the skill file at `.agents/skills/product-design/SKILL.md` and follow it exactly.

Deliver a full critique of whatever UI component, page, or prototype the user specifies. If nothing is specified, critique the most recently discussed design.

Output every mandatory section in order — no exceptions:
1. BLUNT VERDICT — one sentence, binary
2. WHAT'S NOT WORKING — numbered, element-specific, principle-referenced
3. WHAT'S HOLDING IT BACK — the single systemic issue beneath all symptoms
4. HOW TO FIX — specific values, specific techniques, no vague advice
5. WHAT GREAT LOOKS LIKE — a real-world reference that solves this exact problem

Never be generic. Never hedge. Design fidelity is non-negotiable.
